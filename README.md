# ★ 墨染组控台 (Moran GroupDeck)

专为复杂 ComfyUI 工作流打造的**终极分组调度控制台**。告别混乱的节点连线，将你的工作流拆分为多个独立的“大框”（Deck），实现模块化、可视化的精准管控。

## 🌟 核心亮点

- **多面板独立分组**：一个画布可放置无数个“组控台”。你可以将“基础模型”、“采样”、“后处理”拆分到不同的面板，用 `✖` 隐藏不需要的组，真正实现“大框管小框”。
- **直觉化状态开关**：`ON`（绿色）代表模块正常运行放行；`OFF`（灰色）代表节点被 Bypass 跳过。*（注：切换时会智能记忆并恢复节点原有的静音状态，绝不破坏工作流原貌）*
- **极速单组独立运行 `▶`**：点击三角，自动临时旁路其他所有组，**仅运行当前组**。运行结束后，所有开关状态瞬间自动复原！
- **精确耗时监控**：每个组单独计时。跑完后自动在开关旁显示耗时（如 `总:53.7s`，超过60秒自动转为 `1分05秒`），方便排查性能瓶颈，优化模型加载。
- **状态与数据持久化**：面板的所有配置（隐藏了哪些组、上次跑了多久）都会随着工作流 `.json` 文件一起保存。分享给他人，状态原样保留。

## 📦 安装方式

1. 将 `ComfyUI-GroupDeck` 文件夹放入 ComfyUI 的 `custom_nodes` 目录下：
   `ComfyUI/custom_nodes/ComfyUI-GroupDeck`
2. 重启 ComfyUI 后台。
3. 在画布空白处双击搜索 **“墨染”** 或 **“GroupDeck”**，添加 **`★ 墨染组控台`** 节点。

## 🛠️ 界面操作指南

- **`ON / OFF`**：点击切换该组是否执行。绿色放行，灰色跳过。
- **`▶` (运行本组)**：只执行该组内的节点。运行中会变成灰色锁定，防止连点，跑完自动解锁并恢复原状。
- **`✖` (移除)**：将该组从当前面板剔除（不影响画布上的组本身）。
- **`➕` (添加)**：弹出菜单，把被剔除的组重新加回面板。
- **`⟳` (刷新)**：重新扫描画布上的组。如果遇到运行状态卡死，点击此按钮可强制刷新解锁。
- **`--` (时间占位)**：未运行过显示 `--`，运行中显示 `⏳`，运行完毕显示总耗时。
