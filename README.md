# ★ 墨染组控台 (Moran GroupDeck)

专为复杂 ComfyUI 工作流打造的**终极分组调度控制台**。告别混乱的节点连线，将你的工作流拆分为多个独立的“大框”（Deck），实现模块化、可视化的精准管控。

## 🌟 核心亮点

- **双形态自由切换**：既可以在画布上作为一个面板随意拉伸，也可以点击右上角 `🖥️` 唤出**独立悬浮窗**（可随意拖拽，不遮挡画布，完美适配画布缩小场景）。
- **一键点击飞行**：直接点击面板上的组名，画布会瞬间平移并居中飞到该组的位置，再也不怕画布太大找不到组。
- **极速单组独立运行 `▶`**：点击三角，自动临时旁路其他所有组，**仅运行当前组**。运行结束后，所有开关状态瞬间自动复原。
- **精确耗时监控**：每个组单独计时。跑完后自动在开关旁显示耗时（如 `总:53.7s`，超过60秒自动转为 `1分05秒`）。
- **多面板独立分组**：一个画布可放置无数个“组控台”，用 `✖` 隐藏不需要的组，真正实现“大框管小框”。
- **完美数据持久化**：隐藏了哪些组、跑了多久，全部随工作流 `.json` 文件保存。

## 📦 附带节点：墨染多路提示词

本插件包内顺便赠送了 **★ 墨染多路提示词 (Moran MultiPrompt)** 节点。
一个节点包含 3 个独立的大输入框，自带输出端口，可直接连入 CLIP 编码器。无论怎么拉伸节点，输入框都会完美自适应，绝不重叠。

## 🛠️ 安装方式

1. 将 `ComfyUI-Moran-GroupDeck` 文件夹放入 ComfyUI 的 `custom_nodes` 目录下：
   `ComfyUI/custom_nodes/ComfyUI-Moran-GroupDeck`
2. 重启 ComfyUI 后台。
3. 在画布空白处双击，搜索 **“墨染”** 即可找到节点。
